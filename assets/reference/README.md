## 渲染及維護原則

- `data.js` 的 `ITEM_REFERENCES` 指定以上本地圖片為主圖，縮圖及展開圖共用，不先等外站載入失敗。
- 圖片使用 `contain`／`scale-down`，保留帽章完整邊緣、長闊比例；低解像度圖不強制放大。
- 不準確的帽章、基本徽章、皮帶扣、巾圈、小隊章、職級肩章自製 SVG 已移除。未取得可靠本地圖的小隊章／職級肩章只嘗試官方產品圖片；失敗後保留產品連結，不畫一個假的代替。
- 其他一般衣物尚有簡單款式示意後備，必須明示「非實物照片」，不能冒稱為官方相片。兩個來源都失敗時移除壞圖，不設定空 `src`，不重試循環。
- 替換／新增圖片時一併更新本檔來源、`ITEM_REFERENCES`／`LOCAL_UNIFORMS` 及 `tests/images.spec.js`；不要僅憑商品名稱把不同帽章或海／陸／空制服互換。
