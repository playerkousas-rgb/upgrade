# 香港童軍制服準備指南 🏕️

> 由小童軍到領袖 — 家長一目了然的制服準備 APP

## 📌 簡介

原本是港島第82旅的內部工具,現改為**全港旅團通用版本**,幫家長快速了解子女升團時要買什麼、可以沿用什麼。

**6 個支部 × 2 種模式 × 2 個性別 = 完整覆蓋**

| 升團情境 | 涵蓋支部 |
|---|---|
| 由小升幼 | 小童軍 → 幼童軍 |
| 幼升童 | 幼童軍 → 童軍 |
| 童升深 | 童軍 → 深資童軍 |
| 深升樂 | 深資童軍 → 樂行童軍 |
| 樂升領 | 樂行童軍 → 領袖 |
| 深資升領袖 | 深資童軍 → 領袖(直入) |
| 全新加入 | 每支部均有完整制服清單 |

## 🚀 用法

- **本地預覽**:直接打開 `index.html`,或運行 `python3 -m http.server 8080`
- **PWA 安裝**:支援加入主畫面,離線可用
- **響應式**:手機 / 平板 / 桌面三種尺寸自動適配

## 📂 檔案結構

```
.
├── index.html            # 主頁面
├── data.js               # 制服資料庫(6 支部 × 2 模式 × 2 性別)
├── app.js                # 主程式邏輯
├── manifest.webmanifest  # PWA 設定
├── assets/
│   ├── logo-192.png      # APP LOGO 192×192
│   ├── logo-512.png      # APP LOGO 512×512
│   ├── apple-touch-icon.png  # iOS 主畫面 icon
│   ├── favicon-32.png    # 32×32 favicon
│   └── images/           # 各支部 AI 制服插畫
```

## 🎨 LOGO 設計

- **綠色字母 U**(取 Uniform/Upgrade 之義)
- 右上角融入<strong>深綠軟帽 + 金色貝登堡徽章</strong>
