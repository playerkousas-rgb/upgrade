# 獎章原圖暫存區

已收到你上傳的素材。童軍 4 張 `*Award.webp` 可直接使用；深資／樂行 `image-removebg-preview*.png` 是低清／局部去背圖，已製作約 70 KB 的網站縮圖，並清楚標示限制作參考。幼童軍 `Gemini_Generated_Image*.jpg` 是 AI 重繪、不是獎章原圖，暫不採用（避免冒充真章）。實際上線檔案及逐項對照見 [`assets/badges/README.md`](../assets/badges/README.md)。此資料夾只作來源記錄，不部署。

如將來找到官方原圖，請直接上傳到**此資料夾**（GitHub 網頁按「Add file」→「Upload files」）。建議檔名：

- `cub.png` — 幼童軍體驗章、歷奇章、高級歷奇章、金紫荊獎章
- `scout.png` — 童軍探索、標準、高級、總領袖獎章
- `venture.png` — 深資童軍會員章、肩章、段章、深資／榮譽童軍獎章
- `rover.png` — 樂行童軍會員章、肩章、樂行童軍／貝登堡獎章

PNG／JPG／WebP 均可；檔名不同亦可，只要能辨認是哪一支部。**請選擇分支 `arena/9bcd2fd0-upgrade`** 上傳，不要上傳到 `main`。毋須先裁切，請保留圖片四邊和文字，以便核對章樣及來源；盡量只傳這四張，避免加入整份大型 PDF 或含個人資料的截圖。

這是原圖暫存區，已在 `.vercelignore` 排除，**不會當作網站圖片部署**。收到後會按每個獎章裁切、核對對應名稱，壓成小圖放進 `assets/`，並在網站標明來源；不會拿其他章樣充數。

來源參考：[香港童軍總會 2026 支部訓練檢討及各支部綱要](https://sites.google.com/scouting.org.hk/sections/%E6%94%AF%E9%83%A8%E8%A8%93%E7%B7%B4%E6%AA%A2%E8%A8%8E)。
